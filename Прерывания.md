1. Прерывание это событие, которое заставляет процессор прервать текущую задачу и вызвать специальный обработчик
 - внешнее устройство требует внимания
 - произошла ошибка при выполнении инструкции
 - специальная инструкция
2. Прерывания могут происходить асинхронно
 - то есть код не готов к тому, что его прервут
 - то есть обработчик прерывания ответственен за сохранение состояние прерванной задачи
---------------------------------------------------------------------------------
ОТКУДА БЕРУТСЯ ОБРАБОТЧИКИ ПРЕРЫВАНИЙ?
----------------------------------------------------------------------------------
- часть ядра ОС
- ОС сообщает процессору, какой обработчик вызвать в какой ситуации
------------------------------------------------------------------
Error code
-------------------------------------------------------------------
1. Некоторые прерывания соответствуют ошибочным ситуациям
   - для некоторых из них на стек сохраняется Error code
2. Error code, иногда,содержит полезную для обработки ошибки, информацию
   - а иногда он содержит просто 0
-------------------------------------------------------------------
Завершение обработки прерывания 
--------------------------------------------------------------------
- Обработчик прерывания обычно завершается инструкцией iretq
  - для прерывания, сохраняющих Error code, его необходимо удалить со стека
----------------------------------------------------------------------
ТЕЛО ОБРАБОТЧИКА ПРЕРЫВАНИЯ
-----------------------------------------------------------------------
1. В общем случае зависит от прерывания
   - например, прерывания от сетевой карты и от таймера требуют разной обработки
2. Общая часть - сохранение состояния прерванной задачи
   - RIP и RFLAGS не достаточно
   - как минимум, нужно сохранить регистры общего назначения
